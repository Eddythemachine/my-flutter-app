# iNote

iNote is a Flutter application built with Firebase Authentication for secure email/password sign-in, account creation, and email verification. The app uses a modern dark-themed Material 3 interface and a route-based flow for login, registration, verification, and the authenticated dashboard.

## Features

- Email and password registration
- Email and password login
- Firebase email verification flow
- Animated and responsive authentication screens
- Material 3 styling with a custom dark gradient theme
- Route-based navigation for login, register, verify, and home screens

## Tech Stack

## Prerequisites

Before running the project, make sure you have:

- Flutter SDK installed
- A Firebase project created in the [Firebase Console](https://console.firebase.google.com/)
- Android/iOS/Web config files generated for Firebase

## Setup

1. Clone the repository:

```bash
git clone https://github.com/Eddythemachine/my-flutter-app.git
cd my-flutter-app
```

2. Install dependencies:

```bash
flutter pub get
```

3. Configure Firebase for your project:

```bash
flutterfire configure
```

This generates or updates the Firebase configuration files used by the app.

4. Enable Email/Password authentication in Firebase Console:

- Go to Firebase Console
- Open your project
- Navigate to Authentication
- Go to Sign-in method
- Enable Email/Password

5. Run the app:

```bash
flutter run
```

## Firebase Notes

This app depends on Firebase initialization in `main.dart` and uses platform-specific configuration generated by FlutterFire. Ensure that your Firebase project has the correct Android/iOS/Web configuration files in place before running the app.

## App Flow

1. User opens the app
2. If not authenticated, they are redirected to the login screen
3. User can register or sign in
4. New accounts can be verified via email
5. Verified users are taken to the dashboard
